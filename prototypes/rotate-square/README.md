# まわして四角 — prototype 0.2

6×6の共有盤面で、2×2の4枚を時計回りに回す対戦パズル。赤●・青◆・灰−で色以外でも区別できます。

## 遊ぶ

- 練習：時間・操作間隔の制限なし。赤／青を切り替えて回転・得点・補充を確認できます。
- 操作：回したい2×2の左上のマスをダブルタップで回転。1回タップしてプレビューを見てから「回す」ボタンでも操作できます。340ms以内の同じマスへの2回のタップだけを認識し、盤面更新やモード変更でリセットします。
- CPU対戦：画面上部の「CPUと対戦」から開始。自分は赤、CPUは青。3秒カウント後に90秒、双方とも2秒のクールダウン。CPUは約2.5秒に1手、表示されている12枚の補充だけを使って得点と次の一手を評価します。未表示の補充や乱数状態は参照しません。CPU対戦はブラウザ内で動き、部屋や対戦相手は不要です。
- 対戦：一方が「部屋を作る」、もう一方が参加リンクまたは6文字コードで参加。赤の人が開始します。
- 対戦は3秒カウント後90秒。各プレイヤー2秒に1回操作できます。
- 同色2×2が完成すると消去。赤／青は操作した人によらず色の持ち主へ1枚1点。灰は消去のみ。
- 重なる四角のタイルは一度だけ数えます。重力なし。空いたマスを上段・左から補充し、連鎖も同じ規則で処理します。
- 次の補充12枚を表示。初期盤面は各色12枚、180度回転＋赤青入れ替えの対称配置。開始済みの四角がなく、双方に1手で得点可能な操作がある盤面を生成します。
- 盤面バージョンが変わった操作は409で拒否し、クールダウンを消費しません。双方の同時書き込みはD1の比較更新で一方ずつ処理します。
- 部屋は24時間有効。プレイヤーの復帰用トークンはタブのsessionStorageに保存します。URLには含めません。
- 試遊サイトは初期状態で所有者限定。別人との試遊にはサイト側の共有設定が必要です。同じアカウントの別タブ・別端末でも対戦できます。

## 開発

Node.js 22以上。`npm install`（または `pnpm install`）後、`npm run dev`。
バックエンドはVinext + Cloudflare D1。`.openai/hosting.json` のDBバインドと `drizzle/` のマイグレーションが必要です。
Sites以外へ移す場合は、D1のバインド／マイグレーションと認証・公開設定を移行してください。永続DBなしのグローバル変数による部屋管理は行っていません。

## 検証

`node --experimental-strip-types --test tests/*.test.mjs`

練習と対戦は同じ純粋なゲームロジック `lib/game.ts` を使用。得点・補充・時刻・クールダウンは対戦時にサーバーで検証します。
タイルが揃わない操作も許可しているため、準備手・相手への妨害が可能です。面白さと操作間隔の調整は実機プレイで判断します。
